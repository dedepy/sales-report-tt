## Обработка данных

В исходной выгрузке обнаружены полные дубли,
разные варианты написания статусов и пропуски.

- Статусы приводятся к нижнему регистру,
  пробелы по краям удаляются.
- Значение canceled приводится к cancelled.
- Повторяющиеся заказы с одинаковым order_id
  и одинаковыми данными учитываются один раз.
- При противоречивых данных для одного order_id
  программа сообщает об ошибке.
- Четыре пропуска quantity находятся в отменённых
  заказах. Эти заказы учитываются в количестве,
  но не влияют на выручку.
